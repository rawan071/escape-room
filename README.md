# 🧩 Escape Room Algorithm Game

A visually interactive Java Swing game that teaches and demonstrates classic algorithms through an **Escape Room** experience.
Players must solve algorithm-based challenges to clear rooms, unlock doors, and finally escape the control chamber.

Built using **Java Swing GUI** with animated visualizations for sorting and searching algorithms. 

---

# 🎮 Game Concept

The player progresses through **4 themed escape rooms**, where each room focuses on a different algorithm concept.

To clear a room, the player must:

* Answer an algorithm question correctly
* Run the algorithm visualization
* Complete the challenge successfully

Each room becomes unlocked only after the previous room is cleared.

---

# 🏛️ Rooms & Algorithms

| Room   | Theme            | Algorithms                     |
| ------ | ---------------- | ------------------------------ |
| Room 1 | Ancient Library  | Bubble Sort                    |
| Room 2 | Cyber Laboratory | Insertion Sort + Linear Search |
| Room 3 | Secret Vault     | Binary Search                  |
| Room 4 | Control Chamber  | Quick Sort + Merge Sort        |

# 📚 Algorithms Included

## 🔵 Bubble Sort

Used in Room 1 to sort cursed scroll numbers.

### Complexity

* Best Case: O(n²)
* Average Case: O(n²)
* Worst Case: O(n²)

---

## 🟣 Insertion Sort

Used in Room 2 to organize corrupted cyber disks.

### Complexity

* Best Case: O(n)
* Average Case: O(n²)
* Worst Case: O(n²)

---

## 🟢 Linear Search

Used in Room 2 to locate a specific disk.

### Complexity

* Best Case: O(1)
* Worst Case: O(n)

---

## 🟡 Binary Search

Used in Room 3 to find the secret vault code.

### Complexity

* Best Case: O(1)
* Worst Case: O(log n)

---

## 🔴 Quick Sort

Used in Room 4 for fast sorting operations.

### Complexity

* Average Case: O(n log n)
* Worst Case: O(n²)

---

## 🟠 Merge Sort

Used in Room 4 to merge and organize control chamber data.

### Complexity

* Best Case: O(n log n)
* Average Case: O(n log n)
* Worst Case: O(n log n)
